## 🚀 Proyectos destacados

### [NexSale-B2B](https://github.com/enekorodriguezg/NexSale-B2B) · 🚧 en desarrollo
Backend transaccional para la gestión de pedidos y ventas B2B. API REST en **FastAPI** con autenticación **JWT**, control de acceso por roles (administración, comerciales y almacén) y facturas en **PDF y RTF**. Despliegue completo con **Docker Compose**: MySQL y Apache como proxy inverso delante de FastAPI.

`Python` `FastAPI` `SQLAlchemy` `Pydantic` `MySQL` `JWT` `Docker Compose` `Apache`

### [Analítica NLP: WhatsApp frente a Telegram](https://github.com/enekorodriguezg/nlp-whatsapp-telegram-analytics) · 👥 equipo de 4
Pipeline de NLP y Machine Learning que analiza reseñas de usuarios para entender por qué se quedan o se van de cada aplicación: lematización, modelado de temas con **LDA**, comparativa entre clasificadores de **Scikit-learn** y un LLM (**Gemma 2**, few-shot) y dashboards en **Tableau**.

`Python` `Scikit-learn` `Pandas` `NLTK` `TF-IDF` `LDA` `SMOTE` `LangChain` `Ollama` `Tableau`

### [Pokédex: aplicación web full stack](https://github.com/enekorodriguezg/pokedex-flask-manager) · [▶ Demo](https://pokedex-flask-manager.onrender.com)
Plataforma en **Flask** que consume APIs REST externas y las presenta en una interfaz dinámica con **Jinja2**. Arquitectura en **Blueprints**, escalable y con rutas y lógica de negocio separadas.

`Python` `Flask` `Jinja2` `Blueprints` `APIs REST`

### [Automatización de servidores Linux (IaC)](https://github.com/enekorodriguezg/Linux-Server-Automation)
Herramienta de *Infrastructure as Code* en **Bash** que aprovisiona servidores Linux y despliega aplicaciones web: configuración de **Nginx**, gestión automatizada de bases de datos y orquestación de servicios con **systemd**.

`Bash` `Linux` `Nginx` `Gunicorn` `systemd` `MySQL`
